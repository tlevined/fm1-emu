# FM-1 for iPad: the app and the AUv3 plugin

One app with two parts:

- **The FM-1 app**: the emulator's web page in full screen, with the ROM library, the touch panel
  and the Launchpad X / MPK layouts. iPad MIDI (USB, Bluetooth, other apps) reaches the page
  through CoreMIDI. The page runs in Safari's engine, so the emulator's WebAssembly JIT is on, which
  makes this the fastest way to play.
- **The AUv3 plugin "FM-1 Emulator: FM-1"**, for AUM, Loopy Pro, Cubasis, GarageBand and other
  hosts. The host sends it MIDI, and it saves the firmware and its patches with your project.
  iPadOS does not let apps generate machine code at run time, so the plugin runs the emulator's
  interpreter. That is about 3–4× slower than the JIT, so a heavy firmware may need a lower clock
  (Settings → CPU clock).

The two share a folder. Every firmware the app's library keeps shows up in the plugin's
**Firmware** menu. FM-1 SID is built into the plugin, and **Open a .fwsc file…** adds others from Files.

## One-time setup (about 20 minutes, no Mac needed)

Pick a bundle prefix you own, e.g. `com.theron`. Everything below uses it as `PREFIX`.

1. **Identifiers.** In [developer.apple.com](https://developer.apple.com/account/resources/identifiers/list) → Certificates, Identifiers & Profiles → Identifiers:
   - **App Groups** → + → `group.PREFIX.fm1`
   - **App IDs** → + → App → `PREFIX.fm1`. Tick **App Groups**, then Configure → pick the group.
   - The same again for `PREFIX.fm1.au`.
2. **The app's record.** In [App Store Connect](https://appstoreconnect.apple.com) → Apps → + → New App:
   iOS, any unique name (e.g. "FM-1 Emu Theron"), bundle ID `PREFIX.fm1`, any SKU. Nothing
   gets published; TestFlight needs the record.
3. **An API key for GitHub.** App Store Connect → Users and Access → Integrations → App Store
   Connect API → Team Keys → +, with **Admin** access (it lets the build make certificates and
   profiles). Download the `.p8` file (only once). Note the Key ID and the Issuer ID.
4. **GitHub secrets.** In your fork → Settings → Secrets and variables → Actions:
   - Variables tab: `BUNDLE_PREFIX` = `PREFIX`
   - Secrets tab:
     - `TEAM_ID` (developer.apple.com → Membership details)
     - `ASC_KEY_ID`
     - `ASC_ISSUER_ID`
     - `ASC_KEY_P8` = the output of `base64 -w0 AuthKey_XXXX.p8` (Linux) or `base64 -i AuthKey_XXXX.p8` (macOS)
5. **Build.** Actions → **iOS app** → Run workflow. It takes about 20 minutes. App Store Connect
   then processes the build for another 10–30 minutes.
6. **Install.** App Store Connect → your app → TestFlight → Internal Testing → + group → add
   yourself → add the build. Then open the TestFlight app on the iPad and install it. Each new run
   of the workflow becomes a new TestFlight build.

## Playing in a host (AUM shown; Loopy Pro is similar)

1. Open the FM-1 app once, so its library (and any downloads) is copied to the shared folder.
2. In AUM: + → Audio Unit Instruments → **FM-1 Emulator: FM-1**.
3. Route MIDI: your MPK or Launchpad X → the FM-1 plugin.
4. In the plugin: **Settings → Controller layout** → Launchpad X or Akai MPK.
5. For the Launchpad's lights: route the plugin's MIDI output **Launchpad lights** → the
   Launchpad X (its "LPX MIDI" port, not "DAW"). Then **Settings → Send the Launchpad its layout again**.

The layouts are the same as the app's: see `../PWA.md`. **Latency** changes apply when the plugin
is loaded again. If the status bar says *falling behind*, lower the clock.

## Building on a Mac (optional)

With Xcode 26, rustup and `brew install xcodegen`:

```sh
BUNDLE_PREFIX=com.theron DEVELOPMENT_TEAM=ABCDE12345 tools/build_ios.sh
open ios/FM1.xcodeproj
```

## What is where

| | |
|---|---|
| `crates/fm1-ios` | The emulator for iOS: its own thread, lock-free rings to the render block, controller layouts, the panel. C header: `include/fm1_ios.h`. Tested on Linux and macOS: `FM1_TEST_FWSC=pkg.fwsc cargo test -p fm1-ios` |
| `ios/AU` | The AUv3: `FM1AudioUnit` (parameters, render block, project state) and its window (`PanelView`, menus) |
| `ios/App` | The app: a loopback HTTP server for the bundled page, the WKWebView, `MidiBridge` + `midi-shim.js` (Web MIDI from CoreMIDI) |
| `ios/project.yml` | The Xcode project, generated by XcodeGen |
| `.github/workflows/ios.yml` | Build, sign and upload to TestFlight |
